# CampusMarket 视觉规范

本轮界面以微信小程序单手浏览为主：商品照片、价格和面交信息优先；背景保持浅色，只在首页首屏与毕业季专题使用轻量装饰。用户提供的参考图启发了清亮色彩与校园氛围，项目没有复刻其页面、品牌或插画。

## 设计变量

`src/styles/_tokens.scss` 是唯一的主题变量入口。主色为薄荷青 `$primary`，互动强调采用 `$accent`，价格使用 `$price`；背景、卡片、文字、边框和成功/警告/危险状态各有独立变量。间距使用 `$space-1` 至 `$space-8`，圆角使用 `$radius-small`、`$radius-medium`、`$radius-large`、`$radius-card` 与 `$radius-pill`。页面标题、栏目标题、商品名、正文、辅助文案、说明和价格分别有字级变量。

新增页面优先复用变量，不应再为相同语义另写颜色或尺寸。照片保持统一裁切，长标题截断为两行；完整内容放在商品详情展示。

## 公共组件

| 组件 | 用途 |
| --- | --- |
| `AppButton` | 主、次、轻量和危险操作，统一加载与按压反馈 |
| `ProductCard` / `ProductPhoto` | 商品列表、图片错误回退、价格与校区信息 |
| `SearchBar` | 首页搜索入口和分类页实时搜索 |
| `Badge` / `StatusBadge` | 成色、校园身份和在售状态 |
| `EmptyState` / `ProductGridSkeleton` | 搜索、收藏、发布列表的空态和等待反馈 |
| `FormSection` / `ImageUploader` | 发布及编辑资料的表单分组 |
| `TabNav` | 五个主要入口，适配底部安全区与输入键盘 |

图标统一为本地 SVG 线性图标，路径集中在 `src/components/Icon.tsx`。样例商品图为附许可说明的本地缩略图，见 [ASSETS.md](ASSETS.md)。

## 交互原则

- 搜索与排序即时响应；空结果提供清除筛选入口。
- 发布保存、收藏切换和商品状态修改有操作反馈；售出、下架、删除在执行前二次确认。
- 照片选取以小程序压缩图为主，Mock 模式继续沿用原有本地存储与图片清理 Service。
- 固定导航与详情操作栏保留 `safe-area-inset-bottom`；表单输入时隐藏底部导航，避免挡住键盘。
- H5 与小程序共用页面结构。最终适配仍需在微信开发者工具和不同真机宽度上检查图片裁切、长文本、键盘和系统安全区。
